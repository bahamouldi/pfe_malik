\section{Extrait de code : méthode d'augmentation}
L'extrait suivant illustre la logique de génération des grandeurs de flux
(répartition au prorata du temps).

\begin{lstlisting}[language=Python,caption={Augmentation des grandeurs de flux (extrait).}]
# Flux cumules : T1 = moitie du semestre ; 9M = S1 + moitie du 2e semestre
if jun in val and val[jun] is not None:
    nouvelles.append(_ligne(modele, mar, "T1", 0.5 * val[jun]))
if jun in val and dec in val:
    nouvelles.append(_ligne(modele, sep, "9M",
                            val[jun] + 0.5 * (val[dec] - val[jun])))
\end{lstlisting}

\section{Exemples de mesures Power BI}
Les ratios étant déjà calculés dans \texttt{ratios.csv}, Power BI peut être
utilisé avec très peu de DAX. Les mesures suivantes restent utiles pour améliorer
la présentation.

\begin{lstlisting}[language=SQL,caption={Mesures conceptuelles à reproduire dans Power BI.}]
-- Valeur moyenne du ratio selectionne
Valeur ratio = AVERAGE(ratios[Valeur])

-- Ratio sur la derniere annee disponible
Ratio derniere annee =
CALCULATE(
    AVERAGE(ratios[Valeur]),
    ratios[Annee] = MAX(ratios[Annee]),
    ratios[Periode] = "FY"
)
\end{lstlisting}

\section{Requêtes SQL complémentaires}
\begin{lstlisting}[language=SQL,caption={Requêtes SQL complémentaires.}]
-- Evolution annuelle du SGPI de la SFBT
SELECT annee, periode, sgpi_sur_100
FROM v_sgpi
WHERE societe = 'SFBT'
ORDER BY date;

-- Ratios de rentabilite de la SFBT en 2024
SELECT ratio, valeur, unite, benchmark
FROM v_ratios
WHERE societe = 'SFBT'
  AND annee = 2024
  AND periode = 'FY'
  AND categorie = 'Rentabilite';

-- Valeurs financieres estimees de la SFBT
SELECT annee, periode, libelle, valeur
FROM v_etats
WHERE societe = 'SFBT'
  AND type_donnee = 'Estime'
ORDER BY date, libelle;
\end{lstlisting}
